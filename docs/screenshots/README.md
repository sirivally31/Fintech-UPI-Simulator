# Screenshots & Visual Documentation

This directory contains visual assets, architecture diagrams, and interactive Swagger UI screenshots for the **Fintech UPI Simulator**.

---

## Swagger / OpenAPI 3 Interactive Documentation
Access the interactive OpenAPI UI at `http://localhost:8080/swagger-ui.html` when running locally or via Docker Compose.

---

## Container Infrastructure & Health
- **Kafka UI Dashboard**: Available at `http://localhost:8085`
- **Actuator Health Status**: Available at `http://localhost:8080/actuator/health`
